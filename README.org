* Usage

Add this channel to =~/.config/guix/channels.scm=

#+begin_src scheme
  (cons* (channel
          (name 'r0man)
          (url "https://github.com/r0man/guix-channel")
          (branch "main")
          (introduction
           (make-channel-introduction
            "8eb7a76af9b51b80f5c01f18639e6360833fc377"
            (openpgp-fingerprint
             "D226 A339 D8DF 4481 5DDE  0CA0 3DDA 5252 7D2A C199"))))
         %default-channels)
#+end_src

* Development

The development environment is the one this file's =guix.scm= describes.
Build and test from a pure shell (the leading =./= matters, see the header
of =guix.scm=):

#+begin_src sh
  guix shell -D -f ./guix.scm -- make check
#+end_src

=make check= builds every module and runs the SRFI-64 unit tests, including
the Gas City records, activation, provision and home-service tests, and the
check that the generated Gas City record module has not drifted from the
committed JSON schemas.  The root-activation tests run the activation program
inside an unprivileged user namespace (=unshare=) and are skipped when it is
unavailable.

=.github/workflows/check.yml= runs the same command on a runner that has GNU
Guix; it is manual-only (the repository's other runners have no Guix).
